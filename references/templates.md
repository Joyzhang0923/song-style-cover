# 六大意象模板详解

每个模板给出：适合主题、关键词、推荐构图、推荐配色。生成时只取 1–3 个核心意象。

## 模板1：水面涟漪
- 适合主题：情绪、成长、疗愈、时间、关系、回忆
- 关键词：微波、静水、倒影、月白、天青、空灵
- 推荐构图：远景轻轮廓 + 大面积空域；画面下三分之一放一圈极淡涟漪，上方留给标题
- 推荐配色：月白底 + 天青涟漪 + 一点暗金

## 模板2：回音壁
- 适合主题：思想、写作、哲思、品牌主张、文化评论
- 关键词：圆弧、回响、留声、壁面肌理、秩序、静默
- 推荐构图：中轴平衡 + 微弱点题元素；一道淡淡的圆弧墙面，标题居中或偏下
- 推荐配色：米白底 + 淡烟灰肌理 + 鎏金细线

## 模板3：山脊线条
- 适合主题：人生、远方、格局、路径、判断、长期主义
- 关键词：山影、脊线、层峦、雾气、远近层次、东方地形感
- 推荐构图：单侧留白 + 单意象；两三层由深到浅的山脊线，雾气过渡，另一侧留白放标题
- 推荐配色：汝窑青底 + 黛青山影 + 暗金点缀

## 模板4：笔触墨痕
- 适合主题：文字、表达、创作、书写、内观、审美
- 关键词：飞白、枯墨、宣纸、墨痕、笔意、气韵
- 推荐构图：一笔带飞白的墨痕斜穿画面一角，宣纸纹理底，边角一枚小印章
- 推荐配色：米白宣纸 + 墨黑 + 朱红或暗金小印

## 模板5：建筑意象
- 适合主题：文化、城市、品牌、空间、历史、秩序
- 关键词：飞檐、廊柱、瓦当、窗棂、宋式建筑轮廓、几何节奏
- 推荐构图：下沉式题签构图；一角飞檐或一扇窗棂剪影，其余留白
- 推荐配色：月白底 + 黛青剪影 + 鎏金线

## 模板6：器物留影
- 适合主题：生活方式、女性、雅集、茶香、读书、日常审美
- 关键词：瓷器、香炉、卷轴、灯影、花枝、砚台、器物剪影
- 推荐构图：单个器物（如汝窑小盏或一枝花）放在画面一侧，投下柔和影子，另一侧留白
- 推荐配色：天青器物 + 米白底 + 一缕暗金光
